# R2 博客图床

本地命令上传图片，成功后输出公开 URL 和 Markdown。博客部署无需 R2 密钥。
上传工具独立放在 `tools/r2`，不需要先安装整站的构建依赖。

本项目已配置的 bucket 为 `alankyle-images`，公开图片域名为 `https://images.alankyle.com`。
实际上传和公开访问已验证，凭证仅保存在被 Git 忽略的 `.env.r2.local`。

## Cloudflare 配置

1. 在 Cloudflare 控制台启用 R2，创建一个专门存放公开博客图片的 bucket。
2. 在 bucket 的 **Settings → Custom Domains** 绑定图片域名，例如 `images.example.com`，等待状态变为 Active。
   临时测试也可以开启 **Public Development URL**，正式使用请使用自定义域名。
3. 在 R2 概览的 API Tokens 中创建 R2 API Token，权限选择 **Object Read & Write**，范围限制为这个 bucket。
4. 保存生成的 **Access Key ID**、**Secret Access Key**，并记录 Account ID、bucket 名称和 S3 endpoint。
   上传使用 S3 endpoint，文章使用公开图片域名，两者不同。

密钥只填写在本地 `.env.r2.local` 中，不要提交 Git，也不要使用 `VITE_` 前缀。
普通 R2 API Token 字符串不能代替 S3 的 Access Key ID 和 Secret Access Key。
本地上传、文章使用普通 Markdown 图片链接，不需要配置浏览器上传 CORS。

## 本地使用

需要 Node.js 22.9 或更高版本。在项目根目录执行：

```sh
npm run r2:setup
cp .env.r2.example .env.r2.local
```

如果 `.env.r2.local` 已经存在，直接编辑，不要用上面的复制命令覆盖。

```dotenv
R2_ACCOUNT_ID=你的Cloudflare账户ID
R2_ACCESS_KEY_ID=你的AccessKeyID
R2_SECRET_ACCESS_KEY=你的SecretAccessKey
R2_BUCKET=你的存储桶名称
R2_PUBLIC_URL=https://images.example.com
R2_ENDPOINT=
R2_PREFIX=blog
```

默认自动生成普通 bucket 的 S3 endpoint。EU/FedRAMP bucket 请将控制台提供的专用地址填入 `R2_ENDPOINT`。

先预览目标链接（不会联网，也不需要密钥，但需要填 Account ID、bucket 和公开域名）：

```sh
npm run r2:upload -- --dry-run ./public/images/example.png
```

再上传自己的图片，路径有空格时加引号：

```sh
npm run r2:upload -- "/path/to/my photo.png" ./another.webp
```

把输出的 `![描述](https://images.example.com/blog/...)` 粘贴进文章即可。
上传成功表示对象已经写入 R2；公开链接是否能访问还取决于域名绑定及公开访问设置。

支持 PNG、JPEG、WebP、GIF、AVIF、SVG，单张上限 50 MiB。请只上传可信 SVG。
文件使用完整 SHA-256 内容哈希命名，同名不同内容的图片拥有不同链接；相同内容会写到相同对象。
内容变化时 URL 会变化，因此可以设置一年缓存。命令不会删除远程图片或更改现有文章。
多张图片按顺序上传，中途失败时，之前成功的对象仍会保留，修复后可以重试。

## 常见问题

- `Missing configuration`：补齐提示的 `.env.r2.local` 字段。
- `AccessDenied`：检查密钥是否有目标 bucket 的 Object Read & Write 权限。
- `SignatureDoesNotMatch`：检查 Access Key、Secret Key、S3 endpoint 和本机时间。
- 上传成功但图片 404：检查域名是否 Active、是否绑定了正确 bucket，以及 `R2_PUBLIC_URL` 是否填成了公开访问地址。

参考：[S3 SDK 接入](https://developers.cloudflare.com/r2/examples/aws/aws-sdk-js-v3/)、[R2 凭证](https://developers.cloudflare.com/r2/api/tokens/)、[公开访问与域名](https://developers.cloudflare.com/r2/buckets/public-buckets/)。
