## 本地预览

安装依赖后运行 `pnpm dev`。也可运行 `pnpm build` 后通过 `pnpm preview --host 127.0.0.1 --port 3333` 查看构建结果。
修改先在本地检查和预览，集中确认后再推送，避免多次触发 Netlify 部署。
